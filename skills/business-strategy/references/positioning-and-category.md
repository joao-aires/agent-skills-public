# Positioning and Category

## Purpose

Positioning makes the product's value obvious relative to the alternatives customers already understand.

Do not begin with slogans. Begin with the customer's comparison set.

## Positioning sequence

### 1. Competitive alternatives

Ask:

> If this product did not exist, what would the customer use or do instead?

Include manual work, internal build, adjacent products, and doing nothing.

### 2. Unique capabilities

Identify capabilities the important alternatives do not provide well.

Avoid generic claims such as:

- AI-powered
- easy to use
- enterprise-ready
- modern

unless the claim is made concrete and meaningful.

### 3. Value created

Translate capability into customer consequence:

```text
capability → operational effect → economic / strategic value
```

Example:

```text
cross-runtime policy enforcement
→ one governance model across heterogeneous agents
→ lower security burden + less vendor lock-in
```

### 4. Best-fit customer

The best positioning is often specific to a segment for whom the differentiated value matters unusually strongly.

Define:

- context
- trigger
- current alternative
- pain
- buying criteria
- why this segment cares more than the average customer

### 5. Category / frame

Choose a category that gives the buyer a useful reference point.

Options include:

- compete inside an existing category
- create a subcategory
- reframe around a new job / budget
- combine familiar categories
- create a new category only when existing frames materially obscure the value

Category creation is expensive because the company must teach the problem and the product simultaneously.

## Strategic exclusions

Strong positioning says what the company is **not**.

Examples:

- not another agent runtime
- not a consulting-heavy custom implementation
- not a generic horizontal collaboration tool

Exclusions protect product focus and make competitive comparison clearer.

## Wedge versus long-term position

The initial wedge can use a narrow familiar category while the long-term company owns a broader strategic position.

Ensure the wedge does not permanently trap the brand in a low-value category if expansion is central to the thesis.

## Evidence

Positioning should be grounded in:

- customer language
- buying criteria
- competitor claims
- actual workflow
- willingness to pay

Avoid inventing a category from internal product architecture alone.

## Output

Summarize:

```text
For [best-fit customer]
who [important problem / trigger],
[product] is a [category/frame]
that [primary differentiated value].
Unlike [main alternatives],
it [unique capability / mechanism].
```

Use this as a reasoning format, not mandatory marketing copy.
