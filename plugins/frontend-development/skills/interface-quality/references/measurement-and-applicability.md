# Measure the applicable requirement

Use this for quantitative interface recommendations and accessibility findings. Identify the requirement and its conditions before measuring; a numeric result alone cannot establish applicability or conformance. Use the relevant authoritative standard, including [W3C non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) for control-identification claims.

Use a reliable available tool to measure the actual rendered state and the proposed correction. Account for adjacent colors, opacity/compositing and meaningful variants where relevant. A measurement of the existing design does not verify a replacement. State what was measured and which conditions remain unchecked.

Apply the same discipline to interaction claims: exercise the relevant path or mark it unverified. Static appearance cannot establish runtime focus, persistence or recovery. Check the complete recommendation before returning it.
