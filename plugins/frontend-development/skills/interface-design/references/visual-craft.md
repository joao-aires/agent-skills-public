# Distinctive visual craft without generic styling

Read when proposing an unfamiliar product's creative direction, redesigning an interface's identity, or when a rendered design is competent but feels interchangeable with a template. Do **not** activate for routine implementation, minor UI corrections, an accepted design system or a read-only audit with no creative-direction question.

This is an original synthesis inspired by the [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/frontend-design) (Apache-2.0 licensed) and complementary to [visual principles](visual-principles.md), not a reproduction of its prose or assets. Accepted product, platform, accessibility, content and brand decisions always take precedence.

## Derive an intentional point of view

Begin with the product's primary job, actual audience, emotional tone, content, and physical/digital context. Identify one or two characteristic aspects worth making perceptible: perhaps the gravity of operational work, exploratory nature of a knowledge canvas, tactile warmth of a creative product, or clarity of a financial instrument. Translate these into concrete composition, reading rhythm, typography, imagery, color and motion choices rather than decorative domain clichés.

Compare substantially different directions only while a consequential aesthetic decision remains open. For each candidate, describe what becomes prominent, how it supports the main task and what tradeoff it introduces. Make one coherent selection and carry it into a compact palette/type/layout vocabulary with existing semantic roles; avoid generating multiple unsupervised styles on adjacent screens.

## Avoid default-looking output through purposeful choices

Look for signs that the design would read almost the same if the product's name and logo were replaced: uniform rounded cards, repeated generic gradient hero sections, decorative micro-labels, stock dashboard icon grids, arbitrary headline highlights and unrelated motion. These can be appropriate when the task requires them. Critique their *purpose*, not their aesthetic category; do not turn an anti-pattern list into prohibited color families, fonts or shapes.

Let a distinctive feature carry the memorable visual moment, then keep the surrounding system calm and learnable. Try a strong content-specific composition, excellent information hierarchy, deliberate type roles or useful micro-interaction before adding ornamental wrappers. Prefer authentic example content, actual product screenshots or meaningful imagery over invented metrics and abstract filler.

## Typography, motion and expression

Decide whether type should read as expressive, editorial, systematic or utilitarian for the context. Use an intentional type scale, width, emphasis and readable measure. A compact operations table and a storytelling landing page justify different typographic treatment. Keep semantics, contrast, responsive wrapping and localization intact.

Reserve nonessential animation for moments where it adds character or establishes continuity. Feedback motion should explain transitions, changing scope and completion; respect reduced-motion preferences. Avoid duplicating entrance transitions across every element for novelty alone.

## Test creativity against the real interface

Before committing to a direction, render a representative difficult state—not just an ideal landing frame. Compare long text, empty/error, dense data, narrow widths, relevant themes and interaction states. Ask what feels distinctive *because of the product*, what feels arbitrary, and what becomes harder to use. A visual critique from the agent is a hypothesis; human preference or user success needs appropriate evidence.

For a redesign, explicitly map accepted constraints and what may change. Do not overwrite an existing visual identity or install a design library merely because a newly available style seems more expressive. Carry justifiable exceptions into the shared tokens/components rather than creating isolated decorations.
