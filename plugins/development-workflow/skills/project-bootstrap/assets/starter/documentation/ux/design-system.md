# Design system

Use official shadcn new-york-v4 components and local neutral semantic Tailwind tokens. Reuse Button, Input, Label and Card; no extra palette, fonts or icon library. System fonts avoid build-time network dependencies. Screens: auth form, loading status, empty state, saved-note list, inline alert, disabled/pending controls. Labels and native validation remain keyboard accessible. Layout is one responsive max-width column; negative mobile overflow check is committed. No private installed design skill is embedded.
