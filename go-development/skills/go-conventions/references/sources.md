# Go source selection

This original skill retains focused engineering decisions and conditional primary references. The reviewed candidates are useful research material but are not acquired: importing them unchanged would add substantial house policy, orchestration/tool assumptions or a larger linked group. No upstream code, instructions or scripts are copied. A source's popularity does not establish behavioral fit.

Consult [Effective Go](https://go.dev/doc/effective_go) with the actual toolchain, [module dependency management](https://go.dev/doc/modules/managing-dependencies), [context](https://pkg.go.dev/context), [testing](https://pkg.go.dev/testing) and [diagnostics](https://go.dev/doc/diagnostics) for implementation. Follow newer supported API documentation where older examples differ; reading a guide does not upgrade the application's Go version or install tools.

The metadata reference records provenance; it is not a runtime dependency. Public source inspection, valid packages and correctly applied behavior remain different forms of evidence.
