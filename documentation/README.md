## How to use this set

- **New user:** root README, then installation and usage.
- **Contributor:** architecture, metadata, maintainer reference, then the source catalogue.
- **Working a change:** engineering artifacts, the activity you requested and the matching artifact guide.
- **Maintaining an artifact:** its contract, its guide and the handoff reference.

The [artifact catalog](../plugins/sdlc/skills/artifact-system/references/catalog.md) and [guide registry](../plugins/sdlc/skills/artifact-system/references/guide-registry.md) own artifact types and contract/guide pairing. This page owns only the map of repository documentation.

Status statements describe the repository at the current revision. Evaluation records keep their dates and tested revisions; see [recorded evidence and limits](../evals/README.md#recorded-evidence-and-limits).
