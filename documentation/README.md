## Reading order

1. **New user:** root README → installation → SDLC coverage → usage.
2. **Contributor to the collection:** architecture → metadata → maintainer reference → source catalogue.
3. **Working a change:** artifact catalog → artifact workflow → the relevant activity and guide.
4. **Maintaining an artifact:** its contract → its guide → the handoff reference.

Keep this page as the entry point to `documentation/`; do not duplicate the model or the skill catalogue here.
