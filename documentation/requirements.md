## Accessible installed-design inventory

The current session exposes diagram/presentation/image skills, but no specialized application UI/UX skill such as UI/UX Pro Max or frontend-design. The reachable personal checkout has no active personal SKILL.md files. This is evidence only for this session; it cannot establish what is installed in another coding client. Private skill content is never copied into the public repository. The inventory command accepts explicit roots from that client and records metadata/hash/path locally.

## Completion gates

Foundation: requirements ledger, safe package build, task routing, metadata inventory, structure/schema/tests. Client gate: actual discovery and task invocation; unavailable client execution must remain explicitly unverified. Starter gate: clean dependency installation, reviewed migrations, real auth/isolation, persisted browser journey, negative cases, lockfiles and CI evidence. AI/MCP gates are separate and must never be inferred from mocked tests or configuration files.
