# Product feedback analysis: saved search

Status: current. Analysis revision `fb-2026-11`.

## Findings

- Six of eight interviewed researchers save the same broad query and then re-scan results.
- Tags are used informally in note bodies, not as a filter.
- Users ask for "less scrolling", not specifically for more filter controls.

## Limits

- Convenience sample from two teams; no usage telemetry.
- Nobody was observed using the current saved-search screen.

## Open decision

Whether the next slice should be tag filtering or a compact result summary.
