# Legacy evaluation records

These records predate the runnable promptfoo suite in `evals/cases/`. They used different
prompts, inventories, harnesses and models. They are kept for the observations and limits
they recorded, not as comparable results.

- `browser-extension/` — Chrome/MV3 design probes and a disposable runtime trial.
- `engineering-artifact-workspace/assessment.md` — a self-directed ECR workspace walkthrough.
- `independent-scenarios/assessment.md` — four application scenarios with separate reviewers.

Do not cite them as a pass for the current collection. New runs are recorded under `.runs/`
and are not committed unless a decision depends on them.
