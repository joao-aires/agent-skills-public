# Editorial follow-up probes

Two independent agents performed analysis/design tasks from raw synthetic records using the revised source skills. Each received only its task, the named skills, permission to read relevant same-package references and a separate temporary output location. Criteria were recorded outside actor scope before dispatch. No intended recommendation or suspected failure was supplied. The coordinator reviewed the resulting artifacts; no actor revision or coordinator repair followed.

[Inputs, criteria and exact skill fingerprints](inputs-and-criteria.json) identify the candidate. These are direct source-guided probes, not installed-plugin discovery tests. They are separate from the initial authoring/workflow probes in the parent directory.

## Evaluator checks and limits

- Re-read both outputs against all four predeclared criteria per case.
- Checked the four supplied skill fingerprints against source after the runs: unchanged.
- Inspected the temporary task directories: each contains its original input and the requested output only; raw input text matches the criteria record.
- Retained output bytes without rewriting recommendations or concealing limitations.

There was one run per task and no previous-version comparison. These outcomes do not measure human readability, improvement caused by the edits, application behavior or adherence across the 83 authored skills. Editorial review, structural checks and these bounded outcomes support different claims.
