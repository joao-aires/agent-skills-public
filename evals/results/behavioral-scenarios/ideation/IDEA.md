# Rough idea

I want a small **habit tracker** CLI for personal use.

- Track a few daily habits.
- Mark a habit done for today.
- Show the current streak for each habit.
- Keep everything in a local JSON file.
- No third-party dependencies.
- I have not decided the command names, data model or how to handle missed days.

Take this from idea through a useful implementation. Use the installed `sdlc` skills: shape the product outcome, define acceptance, decide the design, implement, test and review. Produce `docs/ecr.md`, `docs/product.md`, `docs/design.md`, `docs/verification.md` and `EVAL.md` in this directory. Do not edit the skill repository.
